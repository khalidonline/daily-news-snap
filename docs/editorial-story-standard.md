# Owner-approved story standard — 2026-09-23

Applies to both daily and local autopilot packages. Runtime instructions live in
`publishing_v2/autopilot/agents.py` (STYLE, researcher, writer, reviewer).

- Introduce the verified current occasion naturally in Info, then a useful distinctive fact.
- An occasion explains why now; never manufacture a historical or causal connection.
- Use everyday Saudi wording, not formal report phrasing such as قصصاً.
- Plan the complete progression: beginning, meaningful development, supported endpoint.
- For ongoing subjects answer where it reached; date milestones accurately. Never invent
  recent statistics when the retrieved sources only establish an older endpoint.
- Every card adds a step. Remove unnecessary relatives, competitors and trivia.
- Preserve the visual identity and a useful red closing on each editorial card.
- Reviewer must reject a readable but incomplete story using existing review checks.

Owner-approved style reference: Saudia gift -> domestic service -> international
expansion -> dated scale milestone. This is a structural example, never evidence
for another package. National Day can be an occasion; unification is not an aviation
cause. Do not hard-code the example's historical facts or passenger figures.

Validation: local existing adapter/evidence/attention/recovery tests; no paid
content generation. Prompt changes are implemented guidance, not proof of autonomous
editorial quality. A subsequent bounded end-to-end trial remains necessary.

## KAFD trial calibration

Run 35908373784 produced a technically complete package for $1.154083. Automatic
review corrected an unsupported vacancy claim and an image mismatch, but accepted
administrative history, secondary designer names, excessive figures and a repeated
endpoint. The manual audit held the package and readiness; it was not published.

Research now prioritizes concrete changes. Writing applies a per-card reader test
and removes names/numbers that do not explain the main takeaway. Review maps these
failures to distinct_value, story_coherent and feedback_respected, independently
of source accuracy. Ownership history remains valid when its documented consequence
matters; chronology alone must not be rewritten as causation.

No paid rerun accompanies this calibration. Existing local tests cannot establish
that future model outputs meet editorial quality; evaluate that separately.
