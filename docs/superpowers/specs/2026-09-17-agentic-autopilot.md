# Agentic autopilot

Approved in conversation on 2026-09-17: implement a coordinator, researcher,
writer, visual producer, independent reviewer, and publisher/monitor. The owner
has approved implementation; rollout starts in shadow mode as discussed.

The daily and local packages each contain one Info card and 2–6 story cards.
Use Saudi everyday Arabic and the established light/Almarai identity. No forced
six-frame story. Current daily triggers expire on the original activation day's
second midnight in Riyadh. Local topics must be broadly relatable Saudi subjects.

Agents receive bounded data, never publishing credentials or callable publishing
tools. Research claims reference retrieved source IDs and verbatim evidence.
The final reviewer sees original evidence and actual rendered pixels in a fresh
request, and must explicitly approve every gate. Review binds to the complete
package and image bytes. A creator cannot supply its own review.

Reuse the existing shared $3/day GitHub CAS budget ledger and reviewed Anthropic
price registry. Every paid call reserves first; unknown outcomes retain their
reservation. Models are configurable within that registry. No paid image calls.
Public-domain/CC0 imagery is the initial automated source; other licenses require
a separately implemented rights adapter, not an LLM declaration of permission.

Bound selection to two candidates and each candidate to two draft/render/review
attempts. Persist slot attempts, decisions, approved package and receipts before
side effects. Never regenerate a slot that has begun publishing. Existing Bundle
durable create journal provides duplicate protection; uncertain creates are held.
Live release requires the deployed shadow validation gate. Default schedule is
shadow, preserving existing approved publishing workflows.

Acceptance: tested rejection, forged/changed approval, expiry, missing evidence,
image failures, budget exhaustion, bounded repair, durable reruns and ambiguous
delivery. Offline tests are not proof of live editorial or provider quality.
