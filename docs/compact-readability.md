# Compact delivery readability gate — 6 October 2026

`python -m publishing_v2.bundle_api validate --manifest …` now requires a
`readability.json` beside the manifest. `publish` requires it before any new
upload/create. Existing per-card post IDs and grouped intents remain eligible
for reconciliation under the existing publisher protections. Partial deliveries
with unsent cards still require the report. Saved Story delivery is unchanged;
it must retain its separate visual review and approval. This is not a claim that
all historical scripts or every alternate publisher has been migrated.

## Report contract, version 1

- `visual_review`: `approved: true` and a nonempty `reference` identifying the
  actual mobile review. This must not be set by a renderer without review.
- `cards`: one or two entries, exactly matching publication order, excluding
  sources. Each entry contains the final JPG/PNG byte `sha256`.
- `headline`, `cta`, and 1–3 `bullets`: each contains actual `text`, `size` in
  pixels, and `box: [left, top, right, bottom]` at **1080×1920**. Record the actual
  renderer arguments; don't substitute requested sizes or a generic PASS.
- Headline: Almarai Bold, at least 48 px, one measured line. Shorten the wording
  if it doesn't fit; do not shrink it. Bullets: Almarai Regular, at least 48 px,
  at most two measured lines each. CTA: Almarai Bold, at least 38 px, at most two
  measured lines, exact copy `شاركها مع صديقك اللي تعجبه هذي المعلومة`.
- Boxes must fit the content safe area and not overlap each other. Text line
  height is reserved at 1.3×font size. A changed image invalidates the report.

The checker remeasures Arabic with the checked-in fonts and checks image bytes,
geometry, sizes and count. It does **not** infer the real font from JPG pixels,
verify photo relevance, detect all unreported text, or replace visual review.
The reviewer must compare the report with a **390 px wide** preview and check
photo, caption, logo, closing line and sharing icon. Table layouts require
separate review; this bullet-based contract does not certify chart readability.
These are our editorial thresholds, not a Snapchat-mandated pixel specification.

First integration target: the upcoming oil pipeline and Google electricity
packages. Both must have final approved copy and actual final images before a
readability report can be approved. No old post is regenerated by this change.
