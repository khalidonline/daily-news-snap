# تطويرات الباقة — ٢٧ سبتمبر ٢٠٢٦

الهدف: تحسين الباقة التالية دون شراء تجارب إنتاج إضافية، مع بقاء سقف المشروع
٣ دولارات يوميًا، وحدود الكتابة والمراجعة ومنع التكرار كما هي.

| التطوير | الربط الحالي | حدوده |
|---|---|---|
| ذاكرة التحرير | `owner_memory.py` يصل للكاتب والمراجعين وتسجل نسخته | ليس استيرادًا آليًا لكل الرسائل القديمة |
| تقييم قبل الإنتاج | `selection_assessment` بعد التحقق من التوقيت والمصادر وتسلسل القصة والصور وقبل الباحث المدفوع | فحص أدلة وجدوى؛ لا يدعي توقع إعجاب الجمهور أو ترتيبًا ذكيًا لكل المرشحين |
| صور كل بطاقة | خطة الصور تصل للكاتب؛ استعلاما بحث اختياريان لكل بطاقة يسبقان البحث العام | لا تعتبر الصورة مطابقة بمجرد تطابق كلمات البحث؛ المراجعة البصرية مستمرة |
| مخزون الجاهز | `autopilot-ready-inventory` يشير لسجل الباقة المختوم وحالتها وصلاحيتها | فهرس للحفظ والاسترجاع، لا ينشر تلقائيًا ولا يمدد الصلاحية لليوم التالي |
| تقرير جودة وتكلفة | ملف `<lane>-quality-cost.json` وسجل دائم `package-report-<slot>` | يشمل الإيصالات المسجلة للحالة؛ الحجز غير المحسوم والمجموع اليومي مرجعهما دفتر التكلفة |
| أداء مرتبط بالباقة | قياسات بمعرفات المنشورات وبنفس ترتيبها وفترة القياس ومصدرها | إدخال موثق فقط؛ لا يوجد سحب تلقائي مثبت لبيانات سناب |

## الاستخدام

ملف الاختيار المجاني الموجود يقبل `queries` في كل عنصر من `image_plan`:

```json
{"asset_id":"verified-photo-id", "purpose":"كشك يوستن التاريخي", "queries":["WHSmith Euston historical bookstall", "كشك يوستن دبليو اتش سميث"]}
```

تستخدم أول عبارتين غير فارغتين؛ تبقى الصور الفعلية وفحص مصدرها واعتماد النص
والمراجعة البصرية مطلوبة. إذا اختصر عدد البطاقات، لا يستخدم الربط بالترتيب؛
تستخدم البطاقة استعلامها الخاص لتجنب إسناد صورة مرحلة أخرى لها.

بيانات الأداء الاختيارية في `editorial/metrics/<slot>.json`:

```json
{
  "source":"Snapchat Insights export — reference to retained evidence",
  "observed_at":"2026-09-29T08:00:00+03:00",
  "window_start":"2026-09-28T08:00:00+03:00",
  "window_end":"2026-09-29T08:00:00+03:00",
  "cards":[{"post_id":"confirmed-post-id-1","views":100}, {"post_id":"confirmed-post-id-2","views":60}]
}
```

الأرقام أعلاه مثال فقط. يجب أن تطابق معرفات إيصال POSTED وترتيبه بالكامل.
القياسات المستقبلية والسالبة وغير المرتبطة بالإيصال تُرفض. صفر مشاهدات البداية
ينتج نسبة غير متاحة، لا قسمة على صفر. النسب وصفية ولا تثبت أثر تعديل واحد،
ولا تقارن بنتائج إعلانات. إعادة تشغيل نفس المسار المحفوظ تسمح بتحديث التقرير
دون إعادة إنتاج؛ قواعد المصالحة والتسليم الحالية تبقى كما هي.

## نتيجة اليوم التالي

التعديل لا يشغّل جدولًا قديمًا ولا ينشئ جدولة أو طلبًا مدفوعًا. يحتاج الإنتاج
ملف اختيار صالح لليوم التالي، ثم اجتياز المراجعة والجاهزية. تغيّر المحرك يبطل
اعتماد المحرك القديم. لا يوجد ضمان نشر تلقائي الساعة الثامنة لمجرد دمج الكود.
الفهرس يحفظ الباقة السليمة؛ ترحيلها للنشر يحتاج إعادة تحقق من الطاري والصلاحية
واعتماد التسليم، دون إعادة إنتاجها تلقائيًا.

تجربة الباقة التالية: تسلسل موثق وصورة لكل مرحلة قبل التصميم؛ نقيس عدد
تصحيحات البطاقات وتكلفة المراحل، وبعد وصول قياسات موثقة نقيس الانتقال بين
أول بطاقتين والإكمال في نافذة ٢٤ ساعة.
