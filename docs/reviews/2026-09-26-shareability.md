# Shareability standard — 2026-09-26

Owner: correct packages that nobody forwards are the failure now. Owner-supplied
examples (Abdullah Fouad car wash / 800 million loss, the Red Sea resort verdict with
side notes, «ما المقصود بـ», the Eid laundry fix) are STYLE references in the prompts,
never evidence.

1. Editor: share_reason is the forwarding sentence «تدري إن ...؟» and the main ranking key.
2. Researcher: SURPRISE HUNT over the whole article; encyclopedia text limit 10,000 ->
   24,000 characters (researcher input bound 90 KB -> 160 KB, other roles unchanged).
3. Writer: Info = hook (most surprising supported fact), story cards end on a supported
   turn, last card pays off. «X: من ... إلى ...» titles banned; text gates reward this
   structure and fail that title pattern.
4. Hooks: three evidence-bound openings (Sonnet), a 22-year-old-Saudi viewer judge
   (Sonnet) picks one, the writer builds on it. Any hook fault falls back to the
   unguided writer; never loses a researched candidate. About $0.05-0.10 per package.

Arrow asides: Almarai has no arrow glyphs, so the side-note technique is written as a
plain short sentence and arrow symbols are rejected before render. Drawn arrows would
be a renderer change (not done).
