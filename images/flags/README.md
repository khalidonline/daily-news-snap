# images/flags/

Curated national flags for place_country story frames. ISO-3166 alpha-2
filenames: `sa.png`, `cn.png`, `us.png`, ...

- Public-domain flag PNGs, added by the owner — **the bot never
  downloads into this folder.** A country frame with no flag on file
  falls to its text-only floor, which is fine.
- Countries only. A city never borrows its country's flag.
- Flags bypass the pixel/graphic check and the vision gate by
  provenance, exactly like curated logos — a flag IS a flat graphic by
  design.
