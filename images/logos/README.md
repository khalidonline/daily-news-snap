Naming: `<slug>-<era>.png` — era is a 4-digit year (`aramco-1938.png`) or
`current` (`aramco-current.png`); `index.json` maps each slug to its Arabic
and Latin names for keyword matching.

Populated via `logo_fetch.py` — story_bot only selects from here, never
downloads into it. Renaming a reviewed candidate into this folder IS the
approval step.
